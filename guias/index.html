Conceptos de Programación

Guías de Estudio — De principiante a las bases de un programador senior

🐍 Ejemplos en Python #️⃣ Ejemplos en C#
📗 Nivel 1 — Fundamentos
Empieza aquí. No se requiere experiencia previa; cada guía se apoya en la anterior.
CP1

Fundamentos de Programación

Qué es programar, variables, tipos de datos, control de flujo, funciones, estructuras de datos y manejo de errores.
CP2

Programación Orientada a Objetos

Clases, objetos, los 4 pilares de la POO, interfaces, composición, principios SOLID y patrones de diseño.
CP3

APIs y Comunicación entre Sistemas

Qué es una API y para qué sirve, HTTP, REST, JSON, autenticación, Postman, webhooks y GraphQL.
CP4

Lo que Todo Programador Debe Saber

Git, bases de datos, testing, clean code y convenciones de nombres, complejidad Big-O, arquitectura y despliegue.
📕 Nivel 2 — Avanzado / Senior
Los temas que se esperan de un desarrollador senior. Requieren haber dominado el Nivel 1.
CP5

Backend Avanzado y Tiempo Real

MVC, patrones de diseño a fondo, asincronía, colas de mensajes, WebSockets, rate limiting y caching.
CP6

Bases de Datos Avanzado

Normalización, SQL avanzado, índices y optimización, transacciones ACID, NoSQL (MongoDB, Redis, DynamoDB) y ORMs.
CP7

DevOps e Infraestructura

Git avanzado (rebase, cherry-pick), CI/CD, Docker y Kubernetes, la nube, Terraform, monitoreo y Nginx.
CP8

Seguridad para Desarrolladores

OWASP Top 10, inyección SQL, XSS, CSRF, HTTPS y TLS, manejo de secretos y principio de menor privilegio.
CP9

Diseño de Sistemas y Liderazgo

System design, escalabilidad, teorema CAP, arquitectura orientada a eventos, y las habilidades blandas del nivel senior.
CP10

Servicios de Red e Infraestructura TI

Servidores y virtualización, SSH, FTP/SFTP, NTP, DNS, DHCP, gestión de servicios en Linux/Windows y troubleshooting de red.

Cada guía incluye exámenes por módulo, glosario ES/EN, flashcards, consejos para entrevistas (con traducción) y registro de estudios.
